# Bounce Service – job card prototype (test sandbox)

Built output of the Service job-card prototype, published with GitHub Pages so the team can test it
on their own phones. Everything runs in the browser: each device keeps its own data, and the test
data (hubs, bikes, parts, stock, users, FIQC checklist) is read from the test-data Google Sheet.

This is a throwaway prototype, not production code. Do not edit these files by hand; they are
replaced on every publish.
